# 药品购进记录"编辑"功能实现计划

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** 在药品购进列表（已入库记录）的操作栏新增"编辑"按钮，允许修改数量/总金额/单价/厂家/日期，并同步更新关联的批次表和药品库存表，保证数据一致性。

**Architecture:** 后端在 `PurchaseController` 新增 `PUT /api/v1/purchases/{id}` 端点（事务内同步更新 purchase_details → drug_batches → drugs 三表）；前端在 `PurchaseView` 已入库行的操作列渲染"编辑"按钮，弹出多字段编辑对话框，保存后刷新列表并广播库存变更信号。

**Tech Stack:** Spring Boot 3.5.9 + MyBatis Plus（后端）、PyQt6（客户端）、MySQL 8.0

---

## 现状与关键事实（已核实）

- 购进入口：`POST /api/v1/purchases/batch`（`PurchaseController.addPurchaseBatch`），每条记录：
  1. 插入 `drug_batches`（新批次：batch_no 自动生成 `YYYYMMDD_HH_mm_drugId`、price=进价、stock_quantity=数量、initial_quantity=数量、manufacturer）
  2. 插入 `purchase_details`（drug_id、quantity、unit、price、total_amount、batch_id=新批次ID、purchase_date、created_at）
  3. 更新 `drugs`（price=本次进价、updated_at），并调 `DrugStockService.updateDrugTotalStock(drugId)` 用 `SUM(drug_batches.stock_quantity)` 重算总库存
  4. AOP `@Log` 插入 `operation_logs` 审计行
- 购进列表：`GET /api/v1/purchases?month=YYYY-MM`（可加 drugName），返回字段：id、drugId、quantity、unit、price、totalAmount、purchaseDate、drugName、manufacturer。**注意：不返回 batchId** —— 编辑时后端按 purchase.id 反查 `purchase_details.batch_id`，无需改 GET 契约。
- 批次库存语义：发药（`VisitServiceImpl` dispense）从 `drug_batches.stock_quantity` 扣减，`initial_quantity` 不变；盘点（`InventoryServiceImpl`）会新建批次。**统计（`StatsServiceImpl`）只读 `purchase_details`（quantity/totalAmount/price），不依赖 initial_quantity** —— 编辑后月度/年度统计自动一致。
- 前端：`client/ui/pharmacist_views.py` 的 `PurchaseView`（1817 行起），9 列表格（状态/日期/药品名称/数量/单位/总金额/单价/生产厂家/操作）。已入库行（`existing_list`）操作列目前是 `"-"` 文本（2223-2225 行），待提交行（`purchase_list`）操作列是"删除"按钮。新增流程中单价 = 总金额/数量 自动计算（2152 行 `unit_price = amount_val / int(qty)`），编辑沿用同一规则。
- `api_client.py` 已有通用 `put()` 方法，前端直接 `api_client.put(f"/purchases/{id}", data=...)`，无需改 api_client.py。

## 设计决策

1. **编辑字段**：数量（必填正整数）、总金额（必填 >0）、生产厂家、购进日期。单价 = 总金额/数量 自动计算（与新增流程一致），对话框只读显示。单位沿用原值，不提供编辑（单位属药品档案属性）。
2. **三表同步规则**（后端事务内，任一失败整体回滚）：
   - `purchase_details`：quantity、price（=新总金额/新数量）、total_amount、purchase_date、manufacturer 不落库（@TableField(exist=false)）；created_at 保持不变。
   - `drug_batches`（batchId 反查，无批次则跳过）：stock_quantity += (新数量 - 旧数量)，**若结果 < 0 抛 BusinessException 拒绝**（该批次已被发药消耗时改小数量会致负库存）；price = 新单价；manufacturer = 新厂家；initial_quantity = 新数量（保持"本批次初始数量"语义，统计不依赖它，安全）。
   - `drugs`：`DrugStockService.updateDrugTotalStock(drugId)` 重算总库存。**drugs.price 参考单价不随编辑更新**（避免旧记录覆盖更新的购进价，保守决策，见开放问题）。
3. **权限**：沿用类级别 `@RequireRole({"DOCTOR", "PHARMACIST"})`，不新增方法级注解。
4. **审计**：新端点加 `@Log("编辑购进记录")`，AOP 自动落 operation_logs。
5. **前端按钮**：已入库行操作列渲染"编辑"按钮（替代 "-" 文本），点击弹出编辑对话框，保存成功后 `load_purchases()` 刷新 + 发 `stock_changed` 信号（库存可能变化，联动药品管理/查询视图刷新）。
6. **校验**：前端对话框预校验（数量正整数、总金额>0）；后端兜底校验 + 负库存校验，错误经 `BusinessException` → HTTP 400 → 前端 `ModernMessageBox.critical` 展示 message。

**Step 1: 新增端点方法**

在 `PurchaseController.java` 末尾（addPurchaseBatch 之后、类结束 `}` 之前）追加：

```java
    // 编辑购进记录：同步更新购进明细、关联批次、药品总库存
    @Log("编辑购进记录")
    @PutMapping("/{id}")
    @Transactional(rollbackFor = Exception.class)
    public Result<String> updatePurchase(@PathVariable Long id,
                                         @RequestBody PurchaseDetail update) {
        // 1. 查原记录（获取旧数量与批次ID）
        PurchaseDetail exist = purchaseMapper.selectById(id);
        if (exist == null) {
            throw new BusinessException("购进记录不存在");
        }
        // 2. 校验新数量（正整数）
        if (update.getQuantity() == null || update.getQuantity() <= 0) {
            throw new BusinessException("数量必须为正整数");
        }
        // 3. 计算新单价：总金额为空时按 数量 x 原单价 兜底
        BigDecimal price = update.getPrice();
        BigDecimal totalAmount = update.getTotalAmount();
        if (totalAmount == null) {
            totalAmount = (price != null ? price : exist.getPrice())
                    .multiply(new BigDecimal(update.getQuantity()));
        }
        if (totalAmount.compareTo(BigDecimal.ZERO) <= 0) {
            throw new BusinessException("总金额必须大于0");
        }
        price = totalAmount.divide(new BigDecimal(update.getQuantity()), 2, RoundingMode.HALF_UP);

        int delta = update.getQuantity() - exist.getQuantity();

        // 4. 更新购进明细
        exist.setQuantity(update.getQuantity());
        exist.setPrice(price);
        exist.setTotalAmount(totalAmount);
        if (update.getPurchaseDate() != null) {
            exist.setPurchaseDate(update.getPurchaseDate());
        }
        purchaseMapper.updateById(exist);

        // 5. 同步批次（库存增减、价格、厂家；无批次则跳过）
        if (exist.getBatchId() != null) {
            DrugBatch batch = drugBatchMapper.selectById(exist.getBatchId());
            if (batch != null) {
                int newStock = batch.getStockQuantity() + delta;
                if (newStock < 0) {
                    throw new BusinessException(
                            "数量调整后该批次库存为负（批次剩余 " + batch.getStockQuantity()
                                    + "，调整 " + delta + "），无法修改");
                }
                batch.setStockQuantity(newStock);
                batch.setInitialQuantity(update.getQuantity());
                batch.setPrice(price);
                if (update.getManufacturer() != null) {
                    batch.setManufacturer(update.getManufacturer());
                }
                drugBatchMapper.updateById(batch);
            }
        }

        // 6. 重算药品总库存（保持 drugs.stock_quantity = SUM(batches) 一致）
        drugStockService.updateDrugTotalStock(exist.getDrugId());

        return Result.success("购进记录已更新");
    }
```

需要补的 import：`org.springframework.web.bind.annotation.PutMapping`、`org.springframework.web.bind.annotation.PathVariable`、`java.math.RoundingMode`。`PurchaseDetail`、`DrugBatch`、`BusinessException`、`@Log`、`@Transactional` 均已导入。

```python
    def edit_existing_purchase(self, row, item):
        """编辑已入库的购进记录：数量/总金额/厂家/日期，单价=总金额/数量 自动计算"""
        dialog = QDialog(self)
        dialog.setWindowTitle(f"编辑购进记录 - {item.get('drugName', '')}")
        dialog.setMinimumWidth(420)
        dialog.setStyleSheet(f"background-color: {WHITE};")

        form = QFormLayout(dialog)
        form.setContentsMargins(24, 24, 24, 24)
        form.setSpacing(14)

        form.addRow("药品:", ModernLabel(item.get('drugName', ''), color=GRAY_600))
        form.addRow("单位:", ModernLabel(item.get('unit', ''), color=GRAY_600))

        qty_input = ModernInput()
        qty_input.setText(str(item.get('quantity', '')))
        qty_input.setToolTip("Enter 下一项")
        form.addRow("数量:", qty_input)

        amount_input = ModernInput()
        amount_input.setText(f"{item.get('totalAmount', 0):.2f}")
        amount_input.setToolTip("Enter 下一项")
        form.addRow("总金额:", amount_input)

        # 单价自动计算（只读展示，与新增流程一致）
        price_label = ModernLabel("", color=GRAY_600)

        def recalc_price():
            try:
                q = float(qty_input.text())
                a = float(amount_input.text())
                if q > 0 and a > 0:
                    price_label.setText(f"单价: {a / q:.2f}")
                    return
            except (ValueError, TypeError):
                pass
            price_label.setText("单价: --")

        qty_input.textChanged.connect(lambda _: recalc_price())
        amount_input.textChanged.connect(lambda _: recalc_price())
        form.addRow("单价:", price_label)

        mfr_input = ModernInput()
        mfr_input.setText(item.get('manufacturer') or '')
        form.addRow("生产厂家:", mfr_input)

        date_edit = SmartDateEdit()
        date_edit.setDate(QDate.fromString(str(item.get('purchaseDate')), "yyyy-MM-dd"))
        form.addRow("购进日期:", date_edit)

        recalc_price()

        btn_layout = QHBoxLayout()
        btn_layout.addStretch()
        ok_btn = ModernButton("保存", variant="primary")
        cancel_btn = ModernButton("取消", variant="secondary")
        btn_layout.addWidget(ok_btn)
        btn_layout.addWidget(cancel_btn)
        form.addRow(btn_layout)

        def save():
            qty_text = qty_input.text().strip()
            amount_text = amount_input.text().strip()
            if not qty_text.isdigit() or int(qty_text) <= 0:
                ModernMessageBox.warning(dialog, "提示", "请输入有效的数量")
                return
            try:
                amount_val = float(amount_text)
                if amount_val <= 0:
                    raise ValueError
            except (ValueError, TypeError):
                ModernMessageBox.warning(dialog, "提示", "请输入有效的总金额")
                return

            data = {
                "quantity": int(qty_text),
                "totalAmount": amount_val,
                "manufacturer": mfr_input.text().strip(),
                "purchaseDate": date_edit.date().toString("yyyy-MM-dd"),
            }
            res = api_client.put(f"/purchases/{item['id']}", data=data)
            if res.status_code == 200 and res.json().get('code') == 200:
                dialog.accept()
                ModernMessageBox.information(self, "成功", "购进记录已更新")
                self.load_purchases()
                mw = self.window()
                if hasattr(mw, 'stock_changed'):
                    mw.stock_changed.emit()
            else:
                msg = res.json().get('message') if res.json() else "未知错误"
                ModernMessageBox.critical(dialog, "失败", f"更新失败: {msg}")

        ok_btn.clicked.connect(save)
        cancel_btn.clicked.connect(dialog.reject)
        dialog.exec()
```

## 风险与开放问题

1. **负库存保护**：数量改小 + 批次已被发药消耗 → 拒绝（已内置校验）。这是保守行为；如需"允许减到 0 但不为负"，校验逻辑已满足。
2. **drugs.price 参考单价不随编辑更新**（决策）：避免旧记录覆盖更新的购进价。若希望"编辑最新批次时同步参考价"，需额外判断该批次是否为该药品最新批次，可在后续需求中补充。
3. **initial_quantity 同步为新数量**：当前统计不依赖它（StatsServiceImpl 只读 purchase_details），安全；但若未来有人按 initial_quantity 还原"原始购进量"会受影响，注释中已说明语义。
4. **编辑日期跨月**：保存后行会从当前月份列表消失（去新月份查看），属预期行为，前端无需特殊处理。
5. **并发**：编辑与发药同时发生时，批次库存以最后一次写为准（无乐观锁）。当前系统为单点桌面场景，可接受；如需严格并发控制，可对批次行加 `SELECT ... FOR UPDATE`（现有 selectBatchesForUpdate 模式可复用）。
